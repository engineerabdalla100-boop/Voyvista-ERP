System Health — Local Storage Usage
Broadcast Message
Real, but scoped honestly: this shows a banner on every page in this browser (stored in local storage). There's no real-time push to other people's devices yet — that needs a backend with WebSockets or similar.
Current Session
Multi-device session tracking, IP logging, and force-logout all require a real backend to know who else is logged in. None of that exists yet — this shows only what's true about the session you're using right now.
Recovery Vault
Not built yet, and here's exactly why: every "delete" button across the app today removes a record permanently and immediately — there's no soft-delete step anywhere to recover from. Building this for real means changing every delete action app-wide to move records to a trash store first, then this page lists and restores from that store. That's real, scoped work — just ask if you'd like it built next.
